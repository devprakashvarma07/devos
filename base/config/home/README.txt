DevOS 2.0 "Whale"
=================

Welcome. This is a real Linux system running our own C compositor —
no Qt, no QML, no third-party desktop shell.

Try these:
  - Ctrl+Alt+T   terminal
  - Ctrl+Alt+F   files
  - Ctrl+Alt+N   notepad
  - Ctrl+Alt+M   system monitor
  - Ctrl+Alt+L   lock screen   (password: devos)
  - Ctrl+Alt+P   status panel (brightness/volume/network)
  - Super        start menu

Everything you see is drawn by /usr/local/bin/devos-comp using
libdrm + FreeType, from source in /usr/src/devos2.

Notes save to ~/Documents/notes.txt (Ctrl+S).
